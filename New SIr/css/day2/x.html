HTML Text Formatting Tags

1. <b> — Bold / Attention

This is bold text.

<b> is mainly used to draw visual attention to text.

2. <strong> — Important Text

WARNING: This action cannot be undone.

<strong> means the content has strong importance.

3. <i> — Alternate / Special Text

The word Bonjour is French.

<i> is commonly used for foreign words, technical terms, or alternate voice.

4. <em> — Emphasis

I really like programming.

<em> tells the browser that this part should be emphasized.

5. <mark> — Highlight

The most important topic today is HTML.

<mark> is used to highlight relevant text.

6. <small> — Small / Fine Print

This is normal text. This is fine print.

<small> is commonly used for copyright, disclaimers and side information.

7. <ins> — Inserted Content

Old price: ₹1000

New price: ₹800

<ins> represents content that has been inserted.

8. <del> — Deleted Content

Original price: ₹1000

<del> represents content that has been deleted.

9. <sup> — Superscript

Mathematical example: X2

Another example: 10th

<sup> moves text above the normal line.

10. <sub> — Subscript

Chemical formula: H2O

Another example: CO2

<sub> moves text below the normal line.
