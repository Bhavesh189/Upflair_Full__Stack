Day 1

Q. 1

What is HTML?

Ans.

HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages. It defines the layout and organization of content by using elements such as headings, paragraphs, images, links, lists, tables, forms, audio, and video. HTML does not control the appearance or styling of a webpage; instead, it works together with CSS for styling and JavaScript for interactivity. Every website on the internet uses HTML as its foundation, making it one of the most essential technologies in web development.

Q. 2

Explain the basic structure of an HTML document.

Ans.

Every HTML document follows a standard structure that begins with the <!DOCTYPE html> declaration, which tells the browser that the document uses HTML5. The <html> tag is the root element containing the entire webpage. Inside it, the <head> section stores metadata such as the page title, character encoding, viewport settings, and links to external CSS or JavaScript files. The <body> section contains all visible content displayed to users, including text, images, forms, videos, and other webpage elements.

Q. 3

What is the difference between HTML and CSS?

Ans.

HTML is responsible for creating the structure and content of a webpage, whereas CSS (Cascading Style Sheets) is responsible for styling and presentation. HTML defines what appears on the page, such as headings, paragraphs, images, and buttons. CSS controls how these elements look by changing colors, fonts, spacing, borders, layouts, animations, and responsiveness. In simple terms, HTML builds the house, while CSS decorates and designs it.

Q. 4

What are semantic HTML elements, and why are they important?

Ans.

Semantic HTML elements clearly describe the purpose of the content they contain. Examples include <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>. These elements improve code readability, help search engines understand the webpage structure for better SEO, and make websites more accessible for screen readers and assistive technologies. Using semantic elements also makes large projects easier to maintain.

Q. 5

What is the difference between block-level elements and inline elements?

Ans.

Block-level elements always start on a new line and occupy the full width available. They are mainly used to create the structure of a webpage. Examples include <div>, <p>, <section>, and heading tags. Inline elements, on the other hand, occupy only the space required by their content and do not start on a new line. Examples include <span>, <a>, <strong>, and <em>. Understanding this difference is essential for designing layouts and applying CSS correctly.

Q. 6

What is the purpose of forms in HTML, and which elements are commonly used?

Ans.

HTML forms are used to collect user input and send it to a server for processing. They are commonly used in login pages, registration forms, search bars, contact forms, feedback forms, and online applications. The main <form> element contains controls such as <input>, <textarea>, <select>, <option>, <label>, and <button>. The action attribute specifies where the data is sent, while the method attribute defines whether the data is submitted using GET or POST.
